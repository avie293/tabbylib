TabbyLib

Config Bibliothek für Avies Mods Config library for Avies mods

Wiki Maven Modrinth

TabbyLib stellt Mods ein gemeinsames Einstellungsmenü bereit. Spieler erreichen es über den Button Tabby Config im Optionsmenü, mit /tabbylib oder – auf NeoForge und Forge – über den „Config“-Button in der Mod-Liste. TabbyLib selbst fügt dem Spiel nichts hinzu; installiere es, wenn eine Mod es braucht (z. B. Day Counter oder Ping Display).

TabbyLib gives mods one shared settings screen. Players open it with the Tabby Config button in the options menu, with /tabbylib or – on NeoForge and Forge – with the "Config" button in the mod list. TabbyLib itself adds nothing to the game; install it when a mod needs it (for example Day Counter or Ping Display).

Für Mod-Entwickler For mod developers

TabbyLib liegt in einem eigenen Maven-Repository. Die Schritt-für-Schritt-Anleitung steht im Wiki.

TabbyLib is available from its own maven repository. The step by step guide is in the wiki.

repositories {
    maven { url = "https://avie29.me/maven" }
}

dependencies {
    // Fabric
    implementation "me.avie29.tabbylib:tabbylib:1.0.0+26.1"
    // NeoForge
    implementation "me.avie29.tabbylib:tabbylib-neoforge:1.0.0+26.1"
    // Forge
    implementation "me.avie29.tabbylib:tabbylib-forge:1.0.0+26.1"
}
