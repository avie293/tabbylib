Modrinth Source code

Ping Display ersetzt die Empfangsbalken in der Tabliste durch den echten Ping in Millisekunden:

  • Eigene Farben für guten, mittleren, schlechten und sehr schlechten Ping
  • Einstellbare Ping-Bereiche und ein fließender Farbverlauf als Alternative zu festen Stufen
  • Optional der Ping auf den Namensschildern anderer Spieler
  • „ms“, Textschatten und der Text für unbekannten Ping sind einstellbar

Ab Ping Display 1.0.0 wird TabbyLib benötigt.

Ping Display replaces the signal bars in the tab list with the real ping in milliseconds:

  • Own colors for good, medium, bad and terrible ping
  • Adjustable ping ranges and a smooth color gradient as an alternative to fixed steps
  • Optionally shows the ping on other players' name tags
  • "ms", text shadow and the text for unknown ping can be changed

From Ping Display 1.0.0 on, TabbyLib is required.
